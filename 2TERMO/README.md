# 🎓 Repositório de Planos de Aula e Materiais Didáticos

Bem-vindo ao repositório central de conteúdos programáticos e guias de aula. Este espaço reúne o planejamento pedagógico e os materiais técnicos estruturados para capacitar estudantes em estruturação web, persistência de dados, lógica de servidores e gestão de entregas.

---

## 📚 Disciplinas e Conteúdos Programáticos

### 1. 🌐 Linguagem de Marcação e Estilização
Focada na estruturação semântica e na apresentação visual de conteúdos para a web, cobrindo desde a marcação de documentos até o design responsivo moderno.
*   **Tecnologias**: HTML5, CSS3, Markdown e noções de formatos de intercâmbio (JSON/XML).
*   **Principais Conceitos**: Semântica web, acessibilidade (a11y), modelos de caixa (*Box Model*), layouts flexíveis (Flexbox e CSS Grid), seletores avançados e design responsivo (Mobile First).

### 2. 🗄️ Banco de Dados (Relacional e Não Relacional)
Dedicada à modelagem, persistência e gerenciamento eficiente de dados para suportar sistemas de alta disponibilidade.
*   **Tecnologias**: SGBDs Relacionais (PostgreSQL, MySQL) e NoSQL (MongoDB, Redis), além de linguagem SQL.
*   **Principais Conceitos**: Modelagem Conceitual e Lógica (DER), normalização de dados, transações ACID, índices, agregações, consultas complexas (*Joins*) e estratégias de cache.

### 3. ⚙️ Desenvolvimento Backend
Base fundamental para a construção da lógica de negócios, design de APIs e arquitetura de servidores de alta performance.
*   **Tecnologias**: Node.js (Express), Python (FastAPI/Django), Java (Spring Boot) e conteinerização básica (Docker).
*   **Principais Conceitos**: Arquitetura RESTful, roteamento, autenticação e autorização (JWT, OAuth), tratamento de exceções, segurança de APIs e integração com bancos de dados.

### 4. 🚀 Gestão e Prática de Projetos
Focada na aplicação de métodos ágeis e tradicionais para organizar o fluxo de desenvolvimento e garantir a entrega de software com qualidade.
*   **Tecnologias**: Jira, Trello, GitHub Projects e ferramentas de Integração Contínua (CI/CD via GitHub Actions).
*   **Principais Conceitos**: Ciclo de vida do projeto, metodologias Ágeis (Scrum e Kanban), planejamento de Sprints, definição de *User Stories*, estimativas de esforço e pipelines de deploy automatizado.
