# 🗄️ Módulo de Banco de Dados

Bem-vindo ao repositório central da disciplina de **Banco de Dados**. Este espaço reúne o planejamento pedagógico, os guias de aula e os materiais técnicos estruturados para capacitar estudantes na modelagem conceitual, projeto lógico e implementação física de bases de dados relacionais.

---

## 🎯 Objetivo da Trilha
Capacitar o estudante a conceber, estruturar e manipular bases de dados relacionais eficientes, aplicando técnicas de modelagem visual e a linguagem SQL para garantir a integridade, consistência e performance das informações.

---

## 📚 Conteúdos Programáticos

### 1. 📐 Modelagem Conceitual com brModelo
Introdução aos fundamentos de projeto de dados através da abstração do mundo real e construção de diagramas conceituais.
*   **Tecnologias**: brModelo (Web/Desktop).
*   **Principais Conceitos**: Conceitos de SGBD, entidades, atributos (simples, compostos, multivalorados), relacionamentos (graus de cardinalidade e participações) e mapeamento conceitual para o modelo lógico.

### 2. 📋 Modelagem Lógica e Normalização
Transição do modelo conceitual para estruturas relacionais otimizadas, garantindo a eliminação de redundâncias e anomalias.
*   **Tecnologias**: brModelo (Conversão para Modelo Relacional) e notação DER.
*   **Principais Conceitos**: Chaves primárias (PK) e estrangeiras (FK), restrições de integridade referencial, e as Formas Normais (1FN, 2FN e 3FN).

### 3. 🐬 Introdução ao MySQL e Linguagem SQL (DDL)
Criação física da estrutura de dados planejada no SGBD relacional utilizando a linguagem de definição de dados.
*   **Tecnologias**: MySQL Server e MySQL Workbench.
*   **Principais Conceitos**: Tipos de dados, comandos de criação, alteração e exclusão de estruturas (`CREATE`, `ALTER`, `DROP`), e aplicação prática de restrições de integridade no banco.

### 4. 🔍 Manipulação e Consultas Avançadas (DML/DQL)
Desenvolvimento de operações de inserção, atualização, remoção e recuperação refinada de dados para atender a regras de negócio.
*   **Tecnologias**: MySQL Server e MySQL Workbench.
*   **Principais Conceitos**: Comandos de manipulação (`INSERT`, `UPDATE`, `DELETE`), consultas básicas e avançadas com filtros (`SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`), funções de agregação e cruzamento de tabelas através de junções (`JOIN`).

*   **Gerenciamento de SGBD**: MySQL Server e MySQL Workbench (ou DBeaver)
