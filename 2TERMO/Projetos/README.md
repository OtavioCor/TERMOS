# 🚀 Módulo de Projetos, Metodologias Ágeis e Prática Integrada

Bem-vindo ao repositório central da disciplina de **Projetos**. Este espaço reúne o planejamento pedagógico, os guias de aula e os materiais técnicos estruturados para capacitar estudantes na gestão de entregas, organização de fluxos de trabalho e desenvolvimento colaborativo de software.

---

## 🎯 Objetivo da Trilha
Capacitar o estudante a planejar, estruturar e executar projetos de software eficientes, aplicando metodologias ágeis e ferramentas modernas para garantir a entrega de soluções funcionais e de alta qualidade.

---

## 📚 Conteúdos Programáticos

### 1. 📋 Fundamentos de Gestão de Projetos e Escopo
Introdução às etapas críticas de planejamento, alinhamento de expectativas e definição dos objetivos de um produto de software.
*   **Tecnologias**: Trello, Jira, Notion.
*   **Principais Conceitos**: Ciclo de vida do projeto, definição de escopo, levantamento de requisitos, cronogramas e alinhamento com stakeholders.

### 2. ⚡ Metodologias Ágeis (Scrum e Kanban)
Organização do fluxo de trabalho e divisão de entregas em ciclos iterativos para maior adaptabilidade e eficiência.
*   **Tecnologias**: GitHub Projects, Trello, Discord/Slack.
*   **Principais Conceitos**: Sprints, papéis no Scrum (Product Owner, Scrum Master, Time de Desenvolvimento), quadros Kanban, reuniões de acompanhamento (*Daily*) e retrospectivas.

### 3. 👥 Trabalho em Equipe e Versionamento Colaborativo (Git/GitHub)
Práticas fundamentais para o desenvolvimento concorrente de código fonte entre múltiplos desenvolvedores sem conflitos.
*   **Tecnologias**: Git, GitHub, Git Flow (Branches, Pull Requests).
*   **Principais Conceitos**: Commits semânticos, estratégias de ramificação, resolução de conflitos, revisões de código (*Code Review*) e fluxo de colaboração em equipe.

### 4. 🚀 Integração, Testes e Entrega Contínua (CI/CD)
Automatização de processos para validação de código e publicação de projetos de forma segura e automatizada.
*   **Tecnologias**: GitHub Actions, Vercel, Netlify.
*   **Principais Conceitos**: Automação de testes básicos, pipelines de build, deploy contínuo e monitoramento de versões em ambiente de produção.

---

## 🛠️ Ferramentas e Ambiente de Desenvolvimento
*   **Gestão de Tarefas**: Trello, Jira ou GitHub Projects
*   **Controle de Versão**: Git e GitHub
*   **Hospedagem e Deploy**: Vercel, Netlify ou GitHub Pages
