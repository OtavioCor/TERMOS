# 💻 Módulo de Desenvolvimento Web e Persistência (HTML, JS & MySQL)

Bem-vindo ao repositório central da disciplina de **Desenvolvimento Web e Persistência**. Este espaço reúne o planejamento pedagógico, os guias de aula e os materiais técnicos estruturados para capacitar estudantes na estruturação semântica de páginas, programação dinâmica e persistência de dados relacionais.

---

## 🎯 Objetivo da Trilha
Capacitar o estudante a construir interfaces web estruturadas com HTML, aplicar lógica e interatividade com JavaScript e gerenciar dados de forma eficiente utilizando o MySQL.

---

## 📚 Conteúdos Programáticos

### 1. 📄 Linguagem de Marcação e Estruturação Semântica (HTML5)
Introdução aos fundamentos da web, estruturação de documentos e acessibilidade de conteúdo.
*   **Tecnologias**: HTML5, Markdown.
*   **Principais Conceitos**: Tags estruturais, semântica web, acessibilidade (a11y), criação de formulários e hierarquia de documentos.

### 2. ⚡ Lógica e Dinâmica Web com JavaScript
Desenvolvimento de comportamento e interatividade no ecossistema web utilizando JavaScript moderno.
*   **Tecnologias**: JavaScript (ES6+), Navegador (DevTools).
*   **Principais Conceitos**: Variáveis, funções, estruturas de controle (`if`, `for`), manipulação do DOM e tratamento de eventos do usuário.

### 3. 🐬 Fundamentos de Banco de Dados Relacional (MySQL)
Introdução ao armazenamento estruturado de dados e à linguagem padrão de consultas para persistência.
*   **Tecnologias**: MySQL Server e MySQL Workbench.
*   **Principais Conceitos**: Tabelas, chaves primárias e estrangeiras, restrições de integridade, e comandos fundamentais SQL (`SELECT`, `INSERT`, `UPDATE`, `DELETE`).

### 4. 🔌 Integração entre Aplicação e Base de Dados
Conexão dos conceitos de interface e lógica de programação com o armazenamento persistente para a criação de sistemas funcionais.
*   **Tecnologias**: Node.js, JavaScript, MySQL Connector.
*   **Principais Conceitos**: Arquitetura cliente-servidor básica, captura de dados enviados via front-end e operações CRUD integradas ao banco.
